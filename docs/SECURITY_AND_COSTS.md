# 信任、权限与费用边界

## 公开工程权限

公共CLI不加载账户、不签署交易，也没有广播方法。RPC白名单仅允许chainId、区块头、eth_call、eth_getCode和eth_getStorageAt。`.env.example`只有RPC空字段。不要向本工程提供私钥或助记词。

发布者签名用于验证原ready、重建和两步报告。原payload中相对研发路径只属于历史证据字段；程序使用公开包的映射，并不访问那些历史路径。包含个人绝对路径的总验收/部署报告只发布明确标注的派生摘要和原记录SHA256，未沿用原签名。新复现者仅生成本地报告，不冒充发布者。

普通快照信任根是所取得的发行包及其中固定的manifest、历史发布者签名和预期摘要。请通过独立可信渠道核对发行包checksum。攻击者如果能替换整个代码和信任根，本地自带hash无法自己建立信任。

历史RPC核对逐项比较真实读取；它信任节点返回的固定区块状态，不是轻客户端或eth_getProof验证。每组前后检查block hash，历史状态缺失绝不回退latest。断连和限流为UNAVAILABLE；数据/身份不一致为FAILED；预算中断为PARTIAL。恢复只复用已保存的同区块同export进度，最终覆盖数必须齐全才PASS_FULL。

## 链上权限图

- 原builder登记并验证固定配置，封存后不能修改页目录/模型配置。
- 每页runtime为STOP+不可变字节，后续合约可直接读取，不依赖原持有人配合。
- 每槽唯一Circuit NFT；deposit检查owner、接口、网表hash并通过safeTransferFrom托管。
- NFT存入者可以取回自己的NFT；取出使未完成轮次失效，全部补齐后才从上一完整逻辑状态重算。
- 运行合约路由位输入并保存Circuit输出，全部必需模块完成才提交逻辑步。
- 底层Factory代理及Beacon可升级，是需要持续关注的外部依赖。代码hash、指针和implementationValid核对不能替代完整权限审计。

59元器件核心、集齐屏障、数据不可变性、状态一致性测试通过，不表示已完成真实资产安全审计。匹配TapeOut源码仍为BLOCKED_SOURCE/未完整匹配；独立安全审计未完成。公开本实验不是主网部署或社区制造批准。

## 成本口径

历史独立NFT数量10419；583464 NAND +31257 LATCH，总614721元器件。物料门数不是项目总费用。

历史测试网累计实际费用约15.8478987074tBNB，其中本阶段deposit0.2015149729tBNB；其余为此前真实数据上传、校验、制造、封存等的累计账目。该派生成功摘要不包含逐笔全部回执审计，也不是当前网络报价或主网费用承诺。测试实例曾采用零材料售价，不能推广为协议恒定免费。

51567个不可变代码页保存204663504字节连接和6502144字节metadata。全部公开链CNS时间步可能需要约814万advance交易（取决于批次策略），没有在该实例执行，不包含在这次离线复现里。电脑运行不花Gas，链核对消耗用户RPC额度。

历史快照读取累计活动耗时约9070秒，读取226464个RPC方法；离线缓存重建18.795秒；两步门级计算/保存134.384秒，进程峰值约628MiB。这三类时间不能混为下载总耗时、实时性或最低配置承诺。本轮独立工程测量另见ACCEPTANCE。

## 输出与崩溃

输入快照只读校验；新结果使用独立目录。检查点先保存到新generation，然后原子发布报告，失败不会覆盖旧检查点。普通运行fsync文件；Node严格Permission Model不支持fsync时保留原子rename和hash校验，报告明确标记 `ATOMIC_HASH_VALIDATED_SANDBOX_FSYNC_UNAVAILABLE`，不承诺突然断电的持久化。恢复仍验证每个文件与状态摘要，损坏时拒绝。
